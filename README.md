# nishiyama-park-app

**いつ行く？西山公園** — 福井県鯖江市「西山公園」に、いつ行くのが一番いいかを答えるWebアプリ。

**オープンデータ活用アプリコンテスト2026**（主催: 鯖江市 / 企画運営: NPO法人エル・コミュニティ）応募作品。

## アプリの内容

鯖江市が公開する日別来訪者数365日分と天気予報（Open-Meteo）を突き合わせ、
訪問日を **見頃 / 天気 / 気温 / ゆとり** の4項目・合計100点で採点する。
配点の比率は入力した条件で変わり、**同じ365日から人によって違う日が返る**。

### 画面

| 画面 | 内容 |
| --- | --- |
| トップ (`/`) | おすすめ日、条件入力、優先度スライダー、候補日ランキング、説明文の自動生成 |
| データ解説 (`/data`) | 使用データ7件、見頃ウィンドウの導出、配点根拠、データ品質に関する注記 |

### 条件入力

目的（特になし / ツツジ / 紅葉 / レッサーパンダ）、訪問可能期間（今週 / 今月 / 次の3連休 / 通年）、
出発地・交通手段、同行者を選ぶと配点が変わり、合計100点に正規化して再計算する。
優先度スライダーは「見頃重視 ⇔ 空いている日重視」の間で見頃とゆとりの配点を連続的に移し替える。

すべて未入力でも既定値（標準プロファイル・今週）で動作する。

### スコアの算出

| 項目 | 標準配点 | 算出根拠 |
| --- | --- | --- |
| 見頃 | 40点 | 日別来訪者数から導出した季節成分のピーク超過率 |
| 天気 | 30点 | 天気区分別の平均来訪者数（休日・平日それぞれで正規化） |
| 気温 | 20点 | 気温帯別の平均来訪者数（帯の境界は線形補間） |
| ゆとり | 10点 | 予想来訪者数の年間パーセンタイル |

**見頃ウィンドウは手で設定していない。** 来訪者数を「季節成分 × 曜日係数 × 天気係数」の積とみなして
反復推定し、曜日と天気の影響を取り除いた季節成分の局所最大点をピーク日、
ピーク超過分が50%を上回る連続範囲を見頃ウィンドウとする。

導出結果は 桜 3/31〜4/14（ピーク4/7）、ツツジ 4/29〜5/10（ピーク5/8）、紅葉 11/15〜11/28（ピーク11/20）。
事前の推定値（ツツジ 5/1〜5/10、紅葉 11/14〜11/25）とほぼ一致することを確認済み。
ウィンドウの日付は導出結果だが、「桜」「ツツジ」「紅葉」という名称の対応づけは人手で行っている
（開花期そのもののデータが公開されていないため）。

予想来訪者数は同じ分解から得た `季節成分 × 曜日係数 × 天気係数` で求める。

### 天気予報の範囲外

Open-Meteo の予報は16日先まで。それ以降の日は、その月の天気出現頻度から期待値を計算し、
画面上で「平年値」と表示する。予報の取得に失敗した場合も同じ経路にフォールバックする。

### 基準日変更モード（デモ用）

審査会は11月開催のため、当日は秋季の挙動しか表示されない。
`?date=2027-05-03` のようにクエリパラメータで基準日を差し替えると、任意の時期の挙動を提示できる。

## 技術スタック

- [Astro](https://astro.build/) — 静的サイト生成、デフォルトJSゼロ配信
- [React](https://react.dev/) — インタラクティブ部分のみアイランドとして配置
- [Tailwind CSS](https://tailwindcss.com/) — スタイリング
- TypeScript (strict)

## 開発

```sh
npm install     # 依存関係のインストール
npm run dev     # 開発サーバー起動 (http://localhost:4321)
npm run build   # ./dist へ本番ビルド
npm run preview # ビルド結果をローカルで確認
npm run typecheck # 型チェック
```

`astro check` は TypeScript 7 系が programmatic API を提供していないため現状は動作しない。
型チェックは `npm run typecheck`（`tsc --noEmit`）を使う。

Node.js 22.12.0 以上が必要です。

### データ変換

`data/raw/` の xls / CSV を `src/data/` の JSON に変換します。生成物はリポジトリに含めているため、
生データを更新したときだけ実行してください。

```sh
npm run build:data
```

### データ上の注意

- 西山公園の入場者数は実測ではなく、**動物園入場者数から機械的に算出された推計値**です
  （4・5・9・10・11月は5倍、それ以外は3倍。令和6・7年度の全24か月で確認）。
  公園と動物園の数字を並べて足すと同じ人を二重に数えることになります。
- 公園入場者数・道の駅入場者数・東側来訪者数は測定方法が異なり、絶対値の比較・合算はできません。
- 東側 日別来訪者数は人流推計にもとづく参考値で、対象は公園全体ではなく東側エリアです。
