# nishiyama-park-app

**いつ行く？西山公園** — 福井県鯖江市「西山公園」に、いつ行くのが一番いいかを答えるWebアプリ。

**オープンデータ活用アプリコンテスト2026**（主催: 鯖江市 / 企画運営: NPO法人エル・コミュニティ）応募作品。

## アプリの内容

鯖江市が公開する日別来訪者数365日分と天気予報（Open-Meteo）を突き合わせ、
訪問日を **見頃40点 / 天気30点 / 気温の快適さ20点 / ゆとり10点** の100点で採点する。

- **今週いつ行くか** — 直近7日をスコア順に並べ、内訳と人出の予想根拠を提示
- **一年のどこに山があるか** — 月別の1日平均来訪者数・平均最高気温・見どころ
- **見頃の裏づけ** — ツツジ5/1〜5/10、紅葉11/14〜11/25。いずれも実測の人出ピークから設定
- **データの注意** — 公園入場者数が推計値であること、10人単位に丸められていることを明示

人出の予想は、当日の天気・気温・平日休日・時期が似ている過去の日を365日から抜き出し、
その中央値を返す。条件を緩める場合も天気は必ず維持する（雨の日が晴天日の実績を拾わないため）。

## 技術スタック

- [Astro](https://astro.build/) — 静的サイト生成、デフォルトJSゼロ配信
- [React](https://react.dev/) — インタラクティブ部分のみアイランドとして配置
- [Tailwind CSS](https://tailwindcss.com/) — スタイリング
- TypeScript (strict)

## 開発

```sh
npm install     # 依存関係のインストール
npm run dev     # 開発サーバー起動 (http://localhost:4321)
npm run build   # ./dist へ本番ビルド
npm run preview # ビルド結果をローカルで確認
```

Node.js 22.12.0 以上が必要です。

### データ変換

`data/raw/` の xls / CSV を `src/data/` の JSON に変換します。生成物はリポジトリに含めているため、
生データを更新したときだけ実行してください。

```sh
npm run build:data
```

### データ上の注意

- 西山公園の入場者数は実測ではなく、**動物園入場者数から機械的に算出された推計値**です
  （4・5・9・10・11月は5倍、それ以外は3倍。令和6・7年度の全24か月で確認）。
  公園と動物園の数字を並べて足すと同じ人を二重に数えることになります。
- 公園入場者数・道の駅入場者数・東側来訪者数は測定方法が異なり、絶対値の比較・合算はできません。
- 東側 日別来訪者数は人流推計にもとづく参考値で、対象は公園全体ではなく東側エリアです。
