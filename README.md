# ICOSSA（イコッサ）

福井に来たら、西山公園へ行こっさ。

福井県鯖江市の「西山公園」を、地図で見て回れる Web アプリです。
アプリ名は福井弁の「行こっさ（行こうよ）」から付けました。
**オープンデータ活用アプリコンテスト2026**（主催: 鯖江市 / 企画運営: NPO法人エル・コミュニティ）の応募作品です。

**アプリはこちら → https://nishiyama-park-app.hiraitakahiro0923.workers.dev**

スマートフォンでもパソコンでも、ブラウザで開くだけで使えます。

## できること

| メニュー | 内容 |
| --- | --- |
| 今日の様子 | 画面上部に、今日の天気と混み具合の目安を表示 |
| 見どころ | ツツジ・紅葉などの見頃の時期と写真 |
| 寄り道 | 公園から半径900m以内の立ち寄りスポットを地図で紹介 |
| アクセス | 駅・バス停から公園までの距離と徒歩時間 |
| ご意見 | 県外から訪れた方の声を集める窓口の提案 |

## 使っているデータ

画面の数字と位置は、すべて公開されているデータから出しています。

- 鯖江市オープンデータ（日別来訪者数・観光・公共トイレ・バス停 ほか / CC BY 2.1）
- 天気予報: [Open-Meteo](https://open-meteo.com/)
- 地図: [地理院タイル](https://maps.gsi.go.jp/development/ichiran.html)（国土地理院）

混み具合は過去の実績にもとづく推計、距離は直線距離です。実際の混雑や所要時間を保証するものではありません。
