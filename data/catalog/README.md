# 鯖江市オープンデータ カタログ調査

調査日: 2026-09-06 / 対象: 西山公園の訪問タイミング提案アプリ

## 取得元

鯖江市のデータセットは CKAN（`ckan.odp.jig.jp`）に登録されているが、
**組織（organization）としては未登録**のため `organization_list` からは見つからない。
鯖江市ポータルの内部エンドポイント経由で全件取得できる。

```
POST https://data.city.sabae.lg.jp/wp/wp-admin/admin-ajax.php
     action=odp_get_opendata&rows=100000
```

- 総数: **1,003件**（本カタログには1,000件を収録）
- ライセンス: 確認した範囲ですべて **CC BY 2.1**
- 形式: CSV / linked RDF が中心。一部 XML・Shape・JPEG
- 文字コードは **UTF-8 と Shift_JIS が混在**（公共トイレ・バス停は Shift_JIS）

`ckan-sabae.json` に全1,000件のメタデータ（タイトル・グループ・形式・URL・更新日）を収録。

## 総務省公共クラウド（別ソース）

観光施設の営業時間・休館日はこちらに入っている。

```
https://ckan.odp.jig.jp/api/3/action/package_show?id=jp-go-soumu-kcloud-kanko-18-odp
http://data.odp.jig.jp/viewcsv/jp/go/soumu/kcloud/kanko_18207.csv
```

鯖江市50件・55列・CC BY 2.1。西山関連8件。**開園時間と休園日が明記されている**:

```
西山動物園      9:00~16:30  休園日：月曜日（祝日の場合は翌日）、年末年始
道の駅西山公園  9:00~18:00  休館日：年末年始
```

また50件中31件が「画像1の著作権の有無：無」付きの公式画像URLを持つ。

注意: **更新日時が2017年、カタログ自体が2018年**。営業時間は現況と異なる可能性があるため、
取得日をUIに明示すること。

### 駐車場リアルタイム満空について

ODPダッシュボードの地図機能が、嚮陽会館前・ふれあい広場（いずれも西山公園）の
満空状況を表示している。内部フィードは実在し、稼働も確認した。

```
https://mixsoda.io:2048/testtest_b.csv?from=-6000
utc,iccid,data
1788663025,8981040000001404255,00000001
```

デバイス2台・約2.5分間隔で更新。ただし**採用は見送る**:

- エンドポイント名が `testtest_b.csv`。安定性の保証がない
- `mixsoda.io:2048` は政府ドメインではない第三者ホスト
- ライセンス表記・ドキュメントが存在しない
- ICCID とどちらの駐車場かの対応表がない
- `data` の値の意味が不明（観測窓では `00000001` 固定）

正規の公開APIが見つかった場合に再検討する。
