# 西山公園メモ

アプリ企画に使えるネタを溜めていく場所。

## 施設・コンテンツ

- **西山動物園のレッサーパンダは入園無料**
  - 園内に併設。無料でレッサーパンダに会える動物園は全国的にも珍しい。
  - 「無料」は県外の人向けの訴求としてかなり強い。旅行の意思決定で効くので、
    アプリ上でも埋もれさせず前面に出す価値がある。

## 施設（画像から確認）

- **日本庭園がある**。池・木橋・東屋・鯉。紅葉期の絵が非常に強い。
  「ツツジの公園」という認知しかないが、庭園の紅葉は単体で観光資源になりうる。

## 園内エリア名（ツツジデータから判明）

- 嚮陽庭園（きょうようていえん）… 日本庭園。ドウダンツツジ。紅葉画像はここと思われる
- 嚮陽会館 / 同駐車場
- パンダらんど（＋駐車場）… 動物園エリア
- 結びの広場
- ピクニック広場（南側階段あり）
- 西山橋（下に緑化ブロック）
- 道の駅西山公園 駐車場

## 四季

- 春: 桜
- 初夏: ツツジ 11種・50,025株（ヒラドツツジが31,400株で全体の63%）
  - 種類ごとに開花期がずれる。サツキは6月まで、ミツバツツジは早咲き。
  - ドウダンツツジは秋に紅葉もする＝春秋2回の見どころ。
- 秋: 紅葉（日本庭園のモミジが見どころ）

## その他

- 道の駅 西山公園が隣接（審査会の会場でもある）

## データ上の重要な注意（検証済み）

- **西山公園入場者数は実測ではなく動物園入場者数からの推計値**
  - `公園 = 動物園 × 5`（4,5,9,10,11月） / `公園 = 動物園 × 3`（6,7,8,12,1,2,3月）
  - 令和6・7年度の全24ヶ月ペアで誤差ゼロの整数倍を確認済み。
  - → 公園と動物園を独立した根拠として並べると二重カウントになる。
  - → 係数自体が示唆的。花のない時期ほど動物園目当ての比率が高い（1/3）と市が想定している。

- **3系列は測定方法が異なり絶対値を比較・合算できない**
  - 公園入場者数（市・参考データ、動物園からの推計）
  - 道の駅入場者数（市・参考データ）
  - 東側来訪者数（Agoop人流推計・端数処理あり・東側限定）

## 動物園の長期推移

- 18年分（平成20年度〜令和7年度）のデータあり。応募作品での差別化材料になる。
- 令和7年度 207,707人は18年で2番目（最高は平成28年度 224,256人）。
- コロナ底の令和2年度 110,512人から +88% のV字回復。
